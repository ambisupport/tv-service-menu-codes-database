## 📺 Major Brand Service Menu Sequences

| Brand | Remote Sequence | Notes / Exit |
| :--- | :--- | :--- |
| **Samsung** | `Mute` + `1 8 2` + `Power` (in Standby) | Alt: `Info` + `Menu` + `Mute` + `Power`. Hold `Exit` 15s for instant reset. |
| **LG** | Hold `OK` (TV) + `OK` (Remote) for 7s | Passwords: `0000`, `0413`, `8741`, `7777`. Set `Hotel Mode = 0` to unlock. |
| **Sony Bravia** | `Display` (i+) + `5` + `Vol (+)` + `Power` (in Standby) | Use `Vol (-)` instead for panel operating hours check. Press `Mute` + `0` to save. |
| **TCL** | `Menu` &rarr; Picture &rarr; Contrast &rarr; `9735` or `1950` | Android TV: Settings &rarr; About &rarr; `Up`, `Right`, `Down`, `Right`, `Up`, `FF`x3, `Rew`x2, `Back`. |
| **Philips** | `0 6 2 5 9 6` + `Info` (or `Menu`) | CSM Mode (Read Only): `1 2 3 6 5 4`. V-Chip bypass PIN: `0711`. |
| **Hisense** | Menu &rarr; Sound &rarr; Balance `0` &rarr; `0 5 3 2` | Master parental reset code: `0000` &rarr; Clean All. |
| **Toshiba** | Menu &rarr; Picture &rarr; `9 3 0 1` | Alt: Hold `Mute` (remote) + press `Menu` (TV chassis). |
| **Panasonic** | Hold `Vol (-)` on TV + press `Recall`/`Info` 3x | Self-check: Hold `Vol (-)` on TV + `Menu` on remote for 5 seconds. |
